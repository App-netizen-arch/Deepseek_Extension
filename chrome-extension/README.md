# Better DeepSeek Local Agent — Chrome MV3

This directory is the production Chrome MV3 bridge for the existing Better DeepSeek extension integration. It does not replace the Better DeepSeek source tree; it connects the browser UI to the existing loopback runtime services.

## Install

1. Build/verify the repository runtime.
2. Open `chrome://extensions` in Chrome.
3. Enable Developer mode.
4. Choose **Load unpacked** and select `chrome-extension/`.
5. Open the extension's Options page.
6. Paste the local runtime bearer token generated by `runtime/scripts/setup-token.mjs`.
7. Verify the Options page reports `Runtime online`.

## Runtime endpoints

- Runtime: `127.0.0.1:3037`
- Code Agent: `127.0.0.1:3038`
- Agent Control: `127.0.0.1:3039`

The extension accepts only loopback runtime endpoints. The manifest permits `chat.deepseek.com` content scripts and local loopback API/WebSocket access.

## BDS tag flow

The content script detects `BDS:*` tags in assistant output, sends them to the MV3 service worker, and the service worker authenticates to the correct local WebSocket. Code Agent tags use the Code Agent socket; Memory/Workflow/MCP tags use the control socket; runtime tags use the main runtime socket.

## Security

The extension stores the bearer token in `chrome.storage.local`. The token is never sent to a non-loopback endpoint. Runtime authentication is required before any WebSocket message is accepted. The runtime itself binds only to `127.0.0.1`.

Do not install this extension from an untrusted source or share the runtime token.
